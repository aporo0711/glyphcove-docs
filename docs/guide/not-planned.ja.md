# やらないことリスト

**English**: [not-planned.md](not-planned.md)

期待と違うものを入れてから気づくのが、お互いにいちばん高くつきます。そこで、**実装する予定のないもの**を先に書いておきます。要望自体はいつでも歓迎です（すべて読みます）が、以下は現在の方針として計画していません。方針を変えるときは、実装より先に CHANGELOG でお知らせします。

1. **テレメトリ・利用状況の収集** — 「文書は端末から出ません」を成立させる根幹です。この方針は変えません
2. **クラウド API による変換・オンラインサービス化** — 変換はすべて端末の中で完結させます
3. **外部 `http(s)` 画像の自動読み込み** — 文書を開いただけで外部通信が起きる設計にはしません（⚠ 既知の例外が 1 つ: 現状の PDF 変換は文書内の外部画像を取得します。抑止を予定 — [詳細](limitations.ja.md)）
4. **アカウント登録・ログイン機能** — ライセンス認証も含め、ネットワークを前提にしません
5. **共同編集・リアルタイム同期** — 他のツールの守備範囲です。本製品が引き受けるのは 1 人で書いて、決められた形式で出すところです
6. **スキャン PDF の OCR** — PDF → Markdown が読むのはテキスト層と描画命令だけです。OCR は誤認識の検証コストを利用者に静かに転嫁するため、載せません
7. **GFM + YAML front matter 以外の Markdown 方言** — 方言を増やすと「同じファイルが場所によって違って見える」問題を持ち込むためです
8. **plantuml.jar の同梱** — どのライセンスの版を使うかは利用者が選べるべきものです（[選びかた](requirements.ja.md)）
9. **更新のたびの通知・お知らせポップアップ** — 作業の邪魔をしません。更新内容は CHANGELOG と Releases でお知らせします
10. **無料版の機能をあとから削ること** — 「無料のまま」と宣言した機能（[料金の予定](../README.ja.md)）をあとから有償に移すことはしません

このリストに載っているものについての質問・要望には、このページへのリンクでお返事することがあります（ご了承ください）。「できるはずなのに動かない」ものは、やらないことではなく不具合です — [FAQ](faq.ja.md) と[既知の正規化・制限](limitations.ja.md)を確認のうえ、[Issues](https://github.com/aporo0711/glyphcove-docs/issues) へお願いします。
