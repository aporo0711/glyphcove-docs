# Contributing to GlyphCove

**日本語は[後半](#glyphcove-への協力のしかた)にあります。**

Thank you for using GlyphCove. This page explains the kinds of contribution we
can accept.

## Bug reports and feature requests — welcome

Please open an issue on the public issue tracker:
**<https://github.com/aporo0711/glyphcove-docs/issues>**

A bug report is most useful when it includes:

- What you did, what you expected, and what happened instead
- The GlyphCove version (Extensions view → GlyphCove), the VS Code version
  (Help → About), and your OS
- If you can, a **minimal Markdown sample** that reproduces the problem —
  please remove anything confidential before attaching it

Feature requests are welcome on the same tracker. Describing the situation you
are in (what you were trying to do when you missed the feature) helps more than
describing a solution.

## Security reports

If you believe you have found a security vulnerability, please **do not open a
public issue**. Use GitHub's private vulnerability reporting on the
[glyphcove-docs repository](https://github.com/aporo0711/glyphcove-docs)
(Security → Report a vulnerability) so the problem is not disclosed before a
fix ships. **[SECURITY.md](SECURITY.md)** has the rest: what to put in a
report, what happens after we receive it, and what is in scope.

## Code contributions — not accepted

GlyphCove is closed-source software, developed in a private repository. The
public repository `glyphcove-docs` carries the documentation and the issue
tracker only, and its contents are copied there automatically — **pull requests
against it cannot be merged**, so please use issues instead. We currently do
not accept code or documentation pull requests.

## GlyphCove への協力のしかた

GlyphCove をお使いいただきありがとうございます。このページは、受け付けている
協力のかたちを説明します。

### バグ報告・機能要望 — 歓迎します

公開のイシュートラッカーへお願いします:
**<https://github.com/aporo0711/glyphcove-docs/issues>**

バグ報告には、次があると助かります。

- 何をして、何を期待し、実際には何が起きたか
- GlyphCove の版（拡張機能ビュー → GlyphCove）、VS Code の版（ヘルプ → バージョン情報）、OS
- 可能なら、問題を再現する**最小の Markdown サンプル**
  （添付の前に、機密にあたる内容は取り除いてください）

機能要望も同じトラッカーで受け付けます。「どういう場面でその機能が無くて
困ったか」を書いていただけると、解決策の提案そのものより役に立ちます。

### セキュリティの報告

脆弱性と思われるものを見つけた場合は、**公開の Issue にしないでください**。
[glyphcove-docs リポジトリ](https://github.com/aporo0711/glyphcove-docs)の
GitHub の非公開脆弱性報告（Security → Report a vulnerability）をお使いください。
修正が届く前に問題が公開されるのを避けるためです。
報告に書くこと・受け取ったあとの流れ・対象の範囲は
**[SECURITY.md](SECURITY.md)** にまとめてあります。

### コードでの貢献 — 受け付けていません

GlyphCove はクローズドソースの製品で、開発は非公開リポジトリで行っています。
公開リポジトリ `glyphcove-docs` が持つのはドキュメントとイシュートラッカーだけで、
中身は自動的に写されます。**そこへの Pull Request は取り込めません**ので、
Issue をお使いください。コード・ドキュメントの Pull Request は現在受け付けていません。
